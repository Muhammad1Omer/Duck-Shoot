# 🦆 Duck Shoot Game  
**An Arcade-Style Shooting Game Developed in Assembly Language**

---

## 📖 Project Overview  
Duck Shoot Game is a classic arcade-style shooting game where players aim to shoot as many ducks as possible within a given time frame. Developed using **MASM615**, this project showcases the fundamentals of low-level programming with engaging gameplay and dynamic features.

The goal: **Achieve the highest score by shooting ducks and managing resources efficiently.**

---

## 🎮 Features  

1. **Game Modes**:  
   - **Mode 1**: Slower and fewer ducks, ideal for beginners.  
   - **Mode 2**: Faster ducks in higher numbers, offering a challenging experience.  

2. **Dynamic Gameplay**:  
   - Ducks move across the screen at varying speeds and altitudes.  
   - Smooth animations and responsive controls.

3. **Score Tracking**:  
   - Real-time scoreboard to display current scores.  
   - Persistent leaderboard storing the highest scores across sessions using file handling.

4. **Rounds and Timer**:  
   - Multiple rounds with increasing difficulty.  
   - Countdown timer for each round to add time pressure.  

5. **Pause and Exit Functionality**:  
   - Players can pause and resume the game anytime.  
   - Easy-to-use exit functionality.  

6. **User Interface**:  
   - Title, menu, and game screens for a seamless user experience.  
   - Displays player names during gameplay.

---

## 🛠️ Technologies Used  
- **MASM615**: For assembly language programming.  
- **File Handling**: For storing player scores and data.  
- **Assembly Debugging Tools**: For troubleshooting and optimization.

---

## 🚧 Challenges Faced  
1. **Duck Movement**:  
   - Initially, ducks didn’t move or glitched significantly.  
   - Debugging animation issues took significant effort.

2. **Scoring Mechanism**:  
   - Early versions didn’t record scores properly.  
   - Fixing this involved optimizing memory and register usage.

3. **Low-Level Debugging**:  
   - Without GPT support for assembly language at the time, debugging required extensive manual analysis.
